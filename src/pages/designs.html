Eight designs, one report.

Every design renders the same report.json, so you can switch the look without touching the content. Pick one in the installer, in config.json, or per report. Your brand colours can override a design's palette.

Showship

The signature design. Every project gets its own colour, carried from the dashboard to the phase tracks, the task tracker and the next-steps table, so the audience can follow a project by colour alone.

Semicircle gauges, pill-track phase charts, a waffle of done and open tasks, a milestone trail for timelines, and ship-trail ribbons on the title slides. A small "Shipped with Showship" mark sits in the footer. Turn it off with "signature": false.

Paper

Set like a printed annual report. Paper background and navy ink, rules instead of cards, one big figure leading every slide, one colour per project. Coral red is kept for risks only.

Every slide type has its own composition. The rows layout does not draw illustrations in this design, so prefer a screenshot or plain rows there.

Ember

A dark deck for rooms where the projector is the brightest thing. Graphite slides, content on flat lighter panels with no shadows or borders, one amber accent for the focal point, and coral red kept for risks only.

Figures are set large in Georgia, and a big slide number sits in the header band. Every slide type has its own composition: a hero panel with one giant figure on the dashboard, vertical pillars for progress, a zigzag trail for timelines and banded rows. The rows layout does not draw illustrations in this design. The theme.dark colour recolours the whole deck, so give it a dark value.

Summit

The executive brief, for a team lead reporting to the CEO or the boss. It is set for a reader who wants the numbers first and has a few minutes to decide. Ink and white with one teal accent for the focal figure, and brick red kept for risks only.

The dashboard is a scoreboard with the key update as a bottom-line strip, decisions come before blockers on the attention slide, and every slide carries "page of total". Timelines, phase bars and task details use the shared card layouts in the Summit look.

Choosing a design

Set it once, or override it for a single report. theme colours still override the design's palette, so you can keep a layout and use your brand colours.

PowerPoint substitutes a font that is not installed, so install the fonts your design needs. Poppins is a free Google font.

Read the design reference

jsonc
// config.json: the default for every report
"style": "vivid"

// report.json: this report only
"style": "paper"

// installer
npx showship --style corporate
